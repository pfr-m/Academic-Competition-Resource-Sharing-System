# 学科竞赛隐私组队系统

这是一个前后端分离的竞赛服务系统演示工程，覆盖竞赛资源发布、经验博客、线下沙龙预约、隐私组队大厅和后台审核管理。

- 前端：Vue 3 + Element Plus。
- 后端：NestJS + JWT + RBAC，目前使用内存数据，方便演示和联调。

## 运行

```bash
npm install
npm run dev
```

默认访问地址：

```text
http://127.0.0.1:5173/
```

## 运行后端

```bash
cd ..\competition-hub-backend
.\mvnw.cmd spring-boot:run
```

## 已实现的演示功能

- 用户角色切换：普通学生、学长学姐、管理员。
- 竞赛资源库：按关键词、竞赛名称、资料类型筛选，模拟安全下载和下载日志计数。
- 经验博客：Markdown 编辑预览、公开/私密、匿名发布、评论开关和二级评论展示。
- 沙龙预约：展示日程、地点、限额，预约后实时扣减并生成个人中心凭证。
- 技术红娘组队：组队卡片、申请加入、队长同意后解锁联系方式。
- 个人隐私中心：真实姓名、微信、手机号可见度设置，个人内容删除。
- 管理后台：内容审核表格、脱敏技能画像、后端架构落点说明。

## 后续接后端建议

- 后端可选 Spring Boot 3.x + MyBatis-Plus 或 NestJS + Prisma。
- JWT 放在统一拦截器中校验身份、角色和数据归属。
- MySQL 8.0 保存用户、博客、资源、沙龙、组队申请。
- Redis 保存预约库存、登录 Token、热门资源和博客排行榜。
- OSS/COS 保存资源文件与博客插图，下载链接应设置短时有效。
- 密码使用 BCrypt，手机号、微信等联系方式按隐私策略脱敏返回。
